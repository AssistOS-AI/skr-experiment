# Semantic engine

`src/engine/index.mjs` is the deterministic reference implementation. Its public exports are `parseSKE`, `printSKE`, `match`, `reason`, `resolve`, `ingestSource`, `applyProcedure`, `auditEvidence`, and `procedureDefinitions`. The implementation uses Node built-ins and may be called synchronously; callers can safely `await` its results.

SKE uses a predicate-first recursive AST: atoms `{type:'atom',value}`, literals `{type:'literal',value}`, numbers `{type:'number',value}`, variables `{type:'variable',name}`, calls `{type:'call',predicate,args}`, conjunctions `{type:'and',terms}`, and queries `{type:'find',variables,body}`. Matching is exact unification, including nested terms and shared variables. It does not treat lexical similarity, weaker predicates, role reversal, or possibility as entailment. Qualified time, attribution, polarity, and modality are retained and cause conservative unresolved results unless aligned.

`reason` replays explicit range-restricted rules to a bounded fixpoint. It rejects rules whose conclusions introduce unbound variables, caps iterations and records, requires premises to share their recorded scope, and retains premise IDs and the rule version on each derived fact. `resolve` handles supplied SKE goals and query joins. It does not claim that it interpreted arbitrary natural-language questions; those remain unresolved for the configured coding-agent adapter to handle. Source scope is applied before reasoning and derived records are admitted only through authorized dependency closure.

The ingestion reference creates one coverage entry per source region and marks semantic extraction as deferred. It does not convert prose into facts. Three procedures are available: `contradiction-audit`, `relevance-synthesis`, and `document-literary-rubric`. They are deterministic procedural scaffolds, not expert or model judgments. Findings retain exact procedure version, parameters, evidence IDs and dependencies.

Evidence audit reopens source regions, checks quote and source-assertion linkage, rejects unauthorized, missing, stale, cyclic and unsupported evidence, and replays explicit rules against pinned premises. Source assertion snapshots must retain the assertion record and original source region. A successful structural match alone does not establish natural-language adequacy.

For a natural-language request without a supplied SKE goal, the reference resolver can expose up to 20 raw source regions in the authorized scope as unverified passage candidates. It does not rank or semantically interpret them, and the answer remains unresolved. The evidence auditor accepts those quotes for inspection only; they cannot support a factual claim without a pinned structured assertion and matching SKE. A new exact SKE assertion can be source-checked only when the complete source region itself is that exact ground SKE expression.

This milestone does not include semantic entity reconciliation, structural/lexical indexes, broad source search, neural interpretation, whole-book extraction, automated materialized-view refresh, or expert literary judgments. The deterministic core only handles supplied SKE and explicit rules; these capabilities need a configured Codex run or a research-grade backend and remain pending.
